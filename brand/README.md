# That Damn Fly: Brand Kit v1

September 13, 2026. Identity to integrate in the first version of the game.

The visual direction was approved: THAT on yellow, DAMN FLY dominant and a brick-eyed fly next to the Y. These resources materialize that direction in clean vectors. The typography was fixed as Archivo Black and the fly was reconstructed with six legs, two wings and two eyes. They are not a pixel-by-pixel reproduction of the generated board.

## Getting started

Import this package as the source of the brand. Do not redraw the logo nor generate AI variants during the implementation. Read the UI/UX Blueprint 1.3 and keep the scope of the Strategic Addendum 1.3 and the Agent Instructions 1.3. The kit adds no features to M0.

1. Keep the SVG originals out of the runtime atlases and import the needed PNGs into Unity.
2. Use the main logo on the start screen and the horizontal one where there is little height. Preserve the aspect ratio; use the accessible name "That Damn Fly".
3. Configure the icons at the project source and validate them in the builds. The native folders are concrete examples for the integration; do not blindly overwrite resources generated by Unity.
4. Integrate the favicon and the web icons in the published template. The HTML and JSON fragments use `/brand/` as an example directory; adapt to the real publication.

## Applying the identity

Colours: ink `#202622`, paper `#F7F0DE`, yellow `#F4CD3C`, eyes `#AF3D2F`. Blue `#2755A5` keeps the information role in the interface. The logo uses Archivo Black; Archivo remains the interface font defined in the blueprint.

Use the main logo from 160 px wide and the horizontal one from 220 px, checking legibility on the real screen. Reserve an outer margin equal to the height of the THAT letters, beyond the exported box. Do not stretch, rotate the whole composition, add a shadow, replace the colours or change the fly between applications. The tilt of the small yellow plate is part of the original.

The color and reverse variants have light wings; reverse is meant for dark backgrounds. The monochrome ones keep the outlines and negative spaces. The simplified favicon variant omits legs that would be lost at 16 px. For the app icon, keep the full fly.

## Unity

For uGUI, import PNGs as 2D/UI Sprites, enable alpha where present, preserve the aspect ratio and validate with sRGB. Choose compression and maximum size after observing the result on the device. Do not force a square texture on a horizontal logo. The outlined SVGs serve as the art source and do not require installing the font on the player's device.

The brand is neither an animation nor a fly controller. The symbol does not replace the flight sprites nor determine behaviour. Do not place the logo over the arena.

## Web

`favicon.ico` contains 16/32/48 px. Separate SVG and PNG up to 64 px, a 180 px touch icon and 192/512 icons for purpose any and maskable are included. Merge `manifest-icons.fragment.json` with the real manifest; it is not a complete manifest and does not create offline cache, a service worker or installation on its own. Adapt paths to the Unity template.

## Apple

The 1024 PNG is square, opaque and without embedded corners or shadow. The catalogue includes the universal iOS base representation. Use the Unity/Xcode icon mechanisms and keep the rest of the generated catalogue. Dark, tinted, clear variations or layered composition with Icon Composer were not produced in this kit. Check the options of the SDK used and the result in the distribution build before submission. No App Store acceptance is claimed.

## Android

The Google Play icon is separate from the launcher icon. The adaptive resources provide foreground, background and monochrome layers, with 108-unit originals and a conservative central figure. The mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi exports are 108/162/216/324/432 px per layer. The legacy versions are 48/72/96/144/192 px.

The XML files reference the resources with the `tdf_` prefix. If the integration uses this native set, configure `android:icon="@mipmap/tdf_launcher"` on the application and resolve any previous `roundIcon`. In Unity, configure the proper icon fields in the project first and adapt the export process. Validate circles, rounded squares, themes and cut-outs on the device. The kit does not automatically change the AndroidManifest of an existing project.

## Editing and reproduction

The SVGs in `svg/` are real vectors, without embedded bitmaps and without dependency on an external font. The drawing is separated into groups and paths. To edit words in the two SVGs of `source/`, install the original TTF from `fonts/`; the font itself stays unchanged. Prefer the outlined SVGs in production.

The scripts in `source/` document the construction. Python 3 with fontTools generates the SVGs; Node with sharp generates PNG, ICO and native resources. Run, on a copy of the package: `python source/build_vectors.py PACKAGE_PATH` and then `node source/export_assets.cjs PACKAGE_PATH`. The commands regenerate and replace the exports of that copy. The visual composition depends on the vectors, not on access to the image generation service.
